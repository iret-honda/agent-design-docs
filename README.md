# テンプレート

設計書11文書とテスト文書6文書のテンプレートを、このフォルダに1ファイルずつ置く。使うときはファイルをコピーし、【 】の部分を埋めて、使わない節は削除する。

- どの文書も、先頭の文書情報表と末尾の改訂履歴は共通
- 上限値や合格ラインなど判定に使う値は、必ず数値で書く
- プロンプト全文や設定値など、実ファイルが正になるものは、転記せずファイルパスを書く
- 【例: …】は記入例である。そのまま残さない
